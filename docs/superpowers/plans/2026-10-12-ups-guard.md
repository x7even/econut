# econut-guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go daemon that reads battery state from NUT and, only when explicitly enabled, powers the rig off when it is on battery with charge below 55% for 120 s.

**Architecture:** `usbhid-ups` -> `upsd` (127.0.0.1:3493) -> `econut-guard`. A pure policy state machine decides; an `Actuator` interface either logs (default, dry-run) or runs `systemctl poweroff`. A small `guard` package wires source, policy and actuator into a poll loop.

**Tech Stack:** Go (standard library only), NUT 2.8.1 text protocol.

**Spec:** `docs/superpowers/specs/2026-10-12-econut-guard-design.md`

## Global Constraints

- Standard library only; no third-party modules.
- Defaults: `--trigger-below 55`, `--debounce 120s`, `--poll 5s`, `--stale-after 300s`, `--ups ecoflow@127.0.0.1:3493`.
- Trigger is strictly `Charge < 55` while `ups.status` contains the token `OB`.
- Dry-run is the default. `systemctl poweroff` may only be constructed when `--enable-shutdown` is passed.
- No test may execute `systemctl`, `shutdown` or `poweroff`; the runner is always injected.
- Invalid or missing NUT data never causes a shutdown.
- Go toolchain: `export PATH=/home/xin/go-toolchain/go/bin:$PATH` (user-local install, go 1.27.2).
- Commits carry no AI attribution lines. Never push to a remote; none is configured.
- Do not modify `/etc/nut`, install services, or run real shutdowns. System setup files are only written to `deploy/` for the user to review and install.

## Review Focus

Failure modes the spec implies that are easy to miss, most likely first. Each has a pinning test in the task named.

1. `ups.status` with extra tokens (`OB DISCHRG`, `OB LB`, `OL CHRG`) and look-alikes (`ROB`): only the exact token `OB` counts. (Task 4)
2. `battery.charge` exactly 55 must not trigger; 54.9 must. (Task 1)
3. NUT replies that are errors or garbage (`ERR DATA-STALE`, non-numeric charge, closed socket, hang): all become invalid samples, never a shutdown. (Task 2)
4. The poweroff command fails: the daemon must retry on the next poll, not go silent. (Task 4)
5. Wall clock steps backwards (NTP) or jumps far forward (suspend/resume): the debounce timer must neither shrink nor be inflated into an early trigger. (Task 1)

	"testing"
	"time"

var t0 = time.Unix(1_000_000, 0)

const step = 5 * time.Second

func cfg() Config {
	return Config{TriggerBelow: 55, Debounce: 120 * time.Second, StaleAfter: 300 * time.Second}
}

func ob(charge float64) Sample { return Sample{OnBattery: true, Charge: charge, Valid: true} }
func ol(charge float64) Sample { return Sample{OnBattery: false, Charge: charge, Valid: true} }

// feed runs samples at fixed intervals starting at t0 and returns the results.
func feed(c Config, st State, samples []Sample, start time.Time) (State, []Result, time.Time) {
	var out []Result
	now := start
	for _, s := range samples {
		var r Result
		st, r = Step(c, st, s, now)
		out = append(out, r)
		now = now.Add(step)
	}
	return st, out, now
}

	out := make([]Sample, n)
	for i := range out {
		out[i] = s
	}
	return out

	var idx []int
	for i, r := range rs {
		if r.Decision == Shutdown {

// Package policy decides when the rig should shut down. It is pure: no I/O,
// no clock reads; the caller supplies samples and timestamps.
package policy

import "time"

// Sample is one reading of the UPS. Valid is false when NUT could not supply
// usable data.
type Sample struct {
	OnBattery bool
	Charge    float64
	Valid     bool
}

type Config struct {
	TriggerBelow float64
	Debounce     time.Duration
	StaleAfter   time.Duration
}

type Decision int

const (
	NoAction Decision = iota
	Shutdown
)

type Result struct {
	Decision Decision
	// StaleOnBattery is true when data has been invalid for longer than
	// StaleAfter and the last valid sample was on battery. It is a warning
	// only; it never causes a shutdown.
	StaleOnBattery bool
}

// State is the policy's memory. The zero value is ready to use.
type State struct {
	// Triggered is true after a Shutdown decision, until the trigger
	// condition stops holding. A caller whose shutdown action failed may
	// clear it to request a retry on the next sample.
	Triggered bool
	// Held is how long the trigger condition has held on consecutive valid
	// samples. Invalid samples neither advance nor reset it.
	Held time.Duration

	prevHeld           bool // previous sample was valid and met the condition
	last               time.Time
	lastValid          time.Time
	lastValidOnBattery bool
}

// Step consumes one sample taken at now and returns the new state and result.
func Step(cfg Config, st State, s Sample, now time.Time) (State, Result) {
	var res Result
	prev := st.last
	st.last = now

	if !s.Valid {
		st.prevHeld = false
		if st.lastValidOnBattery && now.Sub(st.lastValid) > cfg.StaleAfter {
			res.StaleOnBattery = true
		}
		return st, res
	}

	st.lastValid = now
	st.lastValidOnBattery = s.OnBattery

	if !(s.OnBattery && s.Charge < cfg.TriggerBelow) {
		st.Held, st.Triggered, st.prevHeld = 0, false, false
		return st, res
	}

	// Only count the interval since the previous sample when it is positive
	// and no longer than StaleAfter. A backwards clock step or a huge forward
	// jump (suspend/resume, NTP) is treated as a gap, not as time held.
	if dt := now.Sub(prev); st.prevHeld && dt > 0 && dt <= cfg.StaleAfter {
		st.Held += dt
	}
	st.prevHeld = true

	if !st.Triggered && st.Held >= cfg.Debounce {
		st.Triggered = true
		res.Decision = Shutdown
	}
	return st, res
}
```

// returns the raw reply; ok=false closes the connection.
func fakeUPSD(t *testing.T, handle func(cmd string) (reply string, ok bool)) string {
	t.Helper()
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { ln.Close() })
	go func() {
		for {
			c, err := ln.Accept()
			if err != nil {
				return
			}
			go func() {
				defer c.Close()
				sc := bufio.NewScanner(c)
				for sc.Scan() {
					reply, ok := handle(sc.Text())
					if !ok {
						return
					}
					fmt.Fprint(c, reply)

// Package nut is a minimal client for the NUT upsd text protocol.
package nut

import (
	"bufio"
	"context"
	"fmt"
	"io"
	"net"
	"strconv"
	"strings"
	"time"
)

const (
	defaultPort    = "3493"
	defaultTimeout = 5 * time.Second
)

// Reading is one snapshot of the UPS. Status and Charge drive the guard; Vars
// is every variable upsd reports, for monitoring only (nil if unavailable).
type Reading struct {
	Status string            // ups.status, e.g. "OL" or "OB DISCHRG"
	Charge float64           // battery.charge, percent
	Vars   map[string]string // LIST VAR, best effort
}

const maxVars = 2000 // sanity bound on a LIST VAR reply

var unescape = strings.NewReplacer(`\"`, `"`, `\\`, `\`)

type Client struct {
	Addr    string // host:port of upsd
	UPS     string // UPS name in ups.conf
	Timeout time.Duration
}

func (c *Client) timeout() time.Duration {
	if c.Timeout > 0 {
		return c.Timeout
	}
	return defaultTimeout
}

// Read opens one connection and fetches ups.status and battery.charge. Any
// protocol problem, error reply or non-numeric charge is returned as an error.
func (c *Client) Read(ctx context.Context) (Reading, error) {
	d := net.Dialer{Timeout: c.timeout()}
	conn, err := d.DialContext(ctx, "tcp", c.Addr)
	if err != nil {
		return Reading{}, fmt.Errorf("nut: connect %s: %w", c.Addr, err)
	}
	defer conn.Close()
	conn.SetDeadline(time.Now().Add(c.timeout()))
	stop := context.AfterFunc(ctx, func() { conn.Close() })
	defer stop()

	br := bufio.NewReader(conn)
	status, err := get(conn, br, c.UPS, "ups.status")
	if err != nil {
		return Reading{}, err
	}
	chargeStr, err := get(conn, br, c.UPS, "battery.charge")
	if err != nil {
		return Reading{}, err
	}
	charge, err := strconv.ParseFloat(chargeStr, 64)
	if err != nil {
		return Reading{}, fmt.Errorf("nut: battery.charge %q: %w", chargeStr, err)
	}
	// Best effort: monitoring data must never fail a read the guard depends on.
	vars, _ := listVars(conn, br, c.UPS)
	return Reading{Status: status, Charge: charge, Vars: vars}, nil
}

func listVars(w io.Writer, r *bufio.Reader, ups string) (map[string]string, error) {
	if _, err := fmt.Fprintf(w, "LIST VAR %s\n", ups); err != nil {
		return nil, err
	}
	line, err := r.ReadString('\n')
	if err != nil {
		return nil, err
	}
	if strings.TrimRight(line, "\r\n") != "BEGIN LIST VAR "+ups {
		return nil, fmt.Errorf("nut: unexpected reply %q", line)
	}
	vars := make(map[string]string)
	prefix := "VAR " + ups + " "
	for len(vars) <= maxVars {
		line, err := r.ReadString('\n')
		if err != nil {
			return nil, err
		}
		line = strings.TrimRight(line, "\r\n")
		if line == "END LIST VAR "+ups {
			return vars, nil
		}
		rest, ok := strings.CutPrefix(line, prefix)
		name, val, ok2 := strings.Cut(rest, " ")
		if !ok || !ok2 || len(val) < 2 || val[0] != '"' || val[len(val)-1] != '"' {
			return nil, fmt.Errorf("nut: malformed variable line %q", line)
		}
		vars[name] = unescape.Replace(val[1 : len(val)-1])
	}
	return nil, fmt.Errorf("nut: more than %d variables", maxVars)
}

func get(w io.Writer, r *bufio.Reader, ups, name string) (string, error) {
	if _, err := fmt.Fprintf(w, "GET VAR %s %s\n", ups, name); err != nil {
		return "", fmt.Errorf("nut: write: %w", err)
	}
	line, err := r.ReadString('\n')
	if err != nil {
		return "", fmt.Errorf("nut: read %s: %w", name, err)
	}
	line = strings.TrimRight(line, "\r\n")
	if rest, ok := strings.CutPrefix(line, "ERR "); ok {
		return "", fmt.Errorf("nut: %s %s: %s", ups, name, rest)
	}
	rest, ok := strings.CutPrefix(line, fmt.Sprintf("VAR %s %s \"", ups, name))
	if !ok || !strings.HasSuffix(rest, "\"") {
		return "", fmt.Errorf("nut: unexpected reply %q", line)
	}
	return strings.TrimSuffix(rest, "\""), nil
}

// ParseTarget splits "name@host[:port]" into the UPS name and a host:port
// address, defaulting the port to 3493.
func ParseTarget(s string) (ups, addr string, err error) {
	ups, host, ok := strings.Cut(s, "@")
	if !ok || ups == "" || host == "" || strings.ContainsAny(s, " \t") {
		return "", "", fmt.Errorf("invalid UPS target %q, want name@host[:port]", s)
	}
	if _, _, err := net.SplitHostPort(host); err != nil {
		host = net.JoinHostPort(host, defaultPort)
	}
	return ups, host, nil
}

// Package actuator performs (or, by default, only logs) the shutdown.
package actuator

import (
	"context"
	"fmt"
	"log/slog"
	"os/exec"
)

type Actuator interface {
	Shutdown(ctx context.Context, reason string) error
}

// LogOnly is the dry-run actuator. It never touches the system.
type LogOnly struct{ Log *slog.Logger }

func (a LogOnly) Shutdown(_ context.Context, reason string) error {
	a.Log.Warn("WOULD shut down (dry-run, --enable-shutdown not set)", "reason", reason)
	return nil
}

// Runner executes a command. Injected so tests never run real commands.
type Runner func(ctx context.Context, name string, args ...string) error

type Poweroff struct {
	Log *slog.Logger
	Run Runner
}

// NewPoweroff returns a Poweroff wired to the real command runner. This is the
// only constructor that can actually power the machine off.
func NewPoweroff(log *slog.Logger) Poweroff {
	return Poweroff{Log: log, Run: func(ctx context.Context, name string, args ...string) error {
		out, err := exec.CommandContext(ctx, name, args...).CombinedOutput()
		if err != nil {
			return fmt.Errorf("%s: %w: %s", name, err, out)
		}
		return nil
	}}
}

func (a Poweroff) Shutdown(ctx context.Context, reason string) error {
	a.Log.Error("SHUTTING DOWN", "reason", reason)
	return a.Run(ctx, "systemctl", "poweroff")
}

// Package guard wires a UPS source, the policy and an actuator into a poll loop.
package guard

import (
	"context"
	"fmt"
	"log/slog"
	"strings"
	"time"

	"econut/internal/actuator"
	"econut/internal/nut"
	"econut/internal/policy"
)

type Source interface {
	Read(ctx context.Context) (nut.Reading, error)
}

type Guard struct {
	Cfg  policy.Config
	Src  Source
	Act  actuator.Actuator
	Log  *slog.Logger
	Poll time.Duration
	Now  func() time.Time

	st          policy.State
	staleLogged bool
}

// onBattery reports whether ups.status contains the exact token "OB".
func onBattery(status string) bool {
	for _, f := range strings.Fields(status) {
		if f == "OB" {
			return true
		}
	}
	return false
}

func toSample(r nut.Reading, err error) policy.Sample {
	if err != nil {
		return policy.Sample{}
	}
	return policy.Sample{OnBattery: onBattery(r.Status), Charge: r.Charge, Valid: true}
}

// Tick performs one poll: read, decide, and act.
func (g *Guard) Tick(ctx context.Context) {
	r, err := g.Src.Read(ctx)
	if ctx.Err() != nil {
		return
	}
	if err != nil {
		g.Log.Warn("NUT read failed", "err", err)
	}

	st, res := policy.Step(g.Cfg, g.st, toSample(r, err), g.Now())
	g.st = st

	if res.StaleOnBattery {
		if !g.staleLogged {
			g.Log.Error("NUT data stale while on battery", "stale_after", g.Cfg.StaleAfter)
			g.staleLogged = true
		}
	} else {
		g.staleLogged = false
	}

	if res.Decision == policy.Shutdown {
		reason := fmt.Sprintf("on battery, charge %.0f%% < %.0f%% for %s", r.Charge, g.Cfg.TriggerBelow, g.Cfg.Debounce)
		if err := g.Act.Shutdown(ctx, reason); err != nil {
			g.Log.Error("shutdown action failed; will retry on next poll", "err", err)
			g.st.Triggered = false
		}
	}
}

// Run polls immediately and then every Poll until ctx is done.
func (g *Guard) Run(ctx context.Context) {
	t := time.NewTicker(g.Poll)
	defer t.Stop()
	g.Tick(ctx)
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			g.Tick(ctx)
		}
	}
}
```

// Command econut-guard shuts the machine down when the UPS is on battery and
// the charge is low. It only logs unless --enable-shutdown is given.
package main

import (
	"context"
	"flag"
	"fmt"
	"log/slog"
	"os"
	"os/signal"
	"syscall"
	"time"

	"econut/internal/actuator"
	"econut/internal/guard"
	"econut/internal/nut"
	"econut/internal/policy"
)

func validate(trigger float64, debounce, poll, stale time.Duration) error {
	switch {
	case trigger <= 0 || trigger > 100:
		return fmt.Errorf("--trigger-below must be in (0, 100], got %v", trigger)
	case debounce < 0:
		return fmt.Errorf("--debounce must be >= 0, got %s", debounce)
	case poll <= 0:
		return fmt.Errorf("--poll must be > 0, got %s", poll)
	case stale <= 0:
		return fmt.Errorf("--stale-after must be > 0, got %s", stale)
	}
	return nil
}

func main() {
	var (
		target   = flag.String("ups", "ecoflow@127.0.0.1:3493", "NUT UPS as name@host[:port]")
		trigger  = flag.Float64("trigger-below", 55, "trigger when on battery and charge is below this percent")
		debounce = flag.Duration("debounce", 120*time.Second, "condition must hold this long before acting")
		poll     = flag.Duration("poll", 5*time.Second, "poll interval")
		stale    = flag.Duration("stale-after", 300*time.Second, "log an error if NUT data is invalid this long while on battery")
		enable   = flag.Bool("enable-shutdown", false, "actually power the machine off (default: dry-run, log only)")
		once     = flag.Bool("once", false, "read the UPS once, print the reading and exit (diagnostic)")
	)
	flag.Parse()

	log := slog.New(slog.NewTextHandler(os.Stderr, nil))
	if err := validate(*trigger, *debounce, *poll, *stale); err != nil {
		log.Error("bad flags", "err", err)
		os.Exit(2)
	}
	ups, addr, err := nut.ParseTarget(*target)
	if err != nil {
		log.Error("bad flags", "err", err)
		os.Exit(2)
	}
	client := &nut.Client{Addr: addr, UPS: ups, Timeout: *poll}

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	if *once {
		r, err := client.Read(ctx)
		if err != nil {
			log.Error("read failed", "err", err)
			os.Exit(1)
		}
		fmt.Printf("ups.status=%q battery.charge=%v\n", r.Status, r.Charge)
		return
	}

	var act actuator.Actuator = actuator.LogOnly{Log: log}
	mode := "DRY-RUN (no shutdown will occur)"
	if *enable {
		act = actuator.NewPoweroff(log)
		mode = "ENABLED (will power off the machine)"
	}
	log.Info("starting econut-guard", "mode", mode, "ups", *target,
		"trigger_below", *trigger, "debounce", *debounce, "poll", *poll)

	g := &guard.Guard{
		Cfg:  policy.Config{TriggerBelow: *trigger, Debounce: *debounce, StaleAfter: *stale},
		Src:  client,
		Act:  act,
		Log:  log,
		Poll: *poll,
		Now:  time.Now,
	}
	g.Run(ctx)
	log.Info("stopped")
}

`deploy/README.md` (content):
```markdown
# Deploying econut-guard (manual, needs sudo; review each step)

Nothing here is installed automatically.

1. Build: `go build -o bin/econut-guard ./cmd/econut-guard`
2. udev: `sudo cp deploy/99-ecoflow-ups.rules /etc/udev/rules.d/ && sudo udevadm control --reload && sudo udevadm trigger`
3. NUT: copy `nut.conf`, `ups.conf`, `upsd.conf`, `upsd.users` to `/etc/nut/` (set a real password in `upsd.users` first; `chmod 640`, group `nut`). Then `sudo systemctl restart nut-driver-enumerator nut-server`.
4. Check: `upsc ecoflow@localhost` shows `battery.charge` and `ups.status`.
5. Binary: `sudo install bin/econut-guard /usr/local/bin/`
6. Service: `sudo cp deploy/econut-guard.service /etc/systemd/system/` then `sudo systemctl daemon-reload`. Do not enable it until you have run dry-run through a real outage.
7. Enabling real shutdown: add `--enable-shutdown` to `ExecStart` and change `User=` to a user permitted to run `systemctl poweroff` (or use root). Do this only after reviewing the dry-run logs.
```
